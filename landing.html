System requirements

Frequently asked questions

Consensus, eligibility, fees and what it takes to run a node.

Choice Coin is an Algorand Standard Asset, so it inherits Algorand's pure proof-of-stake consensus. Blocks finalise in roughly four and a half seconds with no forks, which is why a ballot is final the moment it confirms.

Eligibility is checked against the on-chain registry before a ballot is accepted: the wallet must hold the governance asset, it must be opted in to the proposal, and it must not already have a recorded ballot. The rules are public, so anyone can reproduce the check.

A ballot is a single transaction, so the network fee is a fraction of an ALGO — typically well under a cent. There is no protocol fee on top, and nothing is charged for reading results.

Yes. The hosted app covers the full lifecycle — draft, publish, collect ballots and export the result. The SDK is there if you would rather embed voting in your own product.

Voting does not require a node — the app talks to public endpoints. If you want to run your own participation node, Algorand's published guidance is a modern quad-core CPU, 8 GB of memory and an SSD with room for the ledger.
